# fanqiao·帆桥（帆桥跨境）

**[fanqiao.net](https://fanqiao.net/)** 官方开源主页 — 基于 **VLESS + XTLS-Vision + REALITY** 现代传输协议的跨境网络加速与海外 AI / 流媒体访问服务，不限设备数、不限速，支持全平台主流代理客户端一键导入。

## 核心技术与服务特性

- **协议栈与抗干扰**：全系主力节点采用 **VLESS + XTLS-Vision + REALITY**，辅以日本 `VLESS + WS + TLS` CDN 备用与 `IPv6 直连` 冗余通道。
- **AI 固定干净出口**：内置策略组隔离 Claude / Claude Code、ChatGPT / Codex CLI、Google Gemini / AI Studio、xAI Grok 与 Cursor，提供 **美国 AI 专线（1x）**、**台湾家宽原生 IP（1x）** 与高纯净 **Claude 专用（1.5x）**。
- **公开遥测监控**：广州探针每 5 分钟自动检测全网线路可用率，公开展示近 7 天 / 30 天统计，不隐藏故障记录 → [`fanqiao.net/status`](https://fanqiao.net/status)（JSON: [`status.json`](https://fanqiao.net/status.json)）。
- **全平台接入教程（38 篇）**：覆盖 Clash Verge Rev、Mihomo Party / FlClash、Shadowrocket（含安全购入与 Apple TV）、Loon / Stash、v2rayN / v2rayNG、sing-box、OpenWrt 软路由、台湾家宽解析、DNS/WebRTC 防泄露与 GitHub SSH / Docker / 终端 TUN 代理 → [`fanqiao.net/guide`](https://fanqiao.net/guide)。
